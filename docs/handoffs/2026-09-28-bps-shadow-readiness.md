## 已实现

1. 实际 BPS HTTP 403 / 500–599 自动降级，包括模型权限错误、纠正请求及原生附件上传；不重放当前失败请求。429 使用 #161 的切号与 BPS 专用冷却。
2. BPS 开启时可选择影子恢复并配置独立常规模型列表。临时降级保留原 BPS 配置；正常业务使用常规模型同名映射，恢复后使用原配置。
3. 首次探测安排在 5 分钟后，失败后依次等待 10、15、20、25、30 分钟，之后保持 30 分钟间隔。后台按分钟扫描，最多三个探测并发，批次循环有总超时限制。
4. 使用现有账号 extra 持久化状态和领取租约，无数据库结构迁移、不创建可调度影子账号。异常、停用、暂停调度、过期、限流/冷却账号不探测。关闭影子恢复保留常规模式，手动关闭 BPS 保存后清除恢复状态。
5. 代理实际配置、凭据、模型设置、手动开关或本轮状态变化时，旧探测不能恢复；同 ID 代理修改受到数据库事务保护。单账号保存漏传已有常规模型列表时保留原列表，批量更新保留局部更新语义。
6. #163 的质量运维规则批量编辑及响应式布局已适配合入。

## 探针口径与实施决定
