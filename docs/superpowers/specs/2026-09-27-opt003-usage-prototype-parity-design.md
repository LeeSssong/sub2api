# OPT-003 使用记录原型结构对齐

冻结基线：`artifacts/opt-003-v02-baseline/ux-prototype-source.tar.gz`，SHA-256 `5a0beaa34e13f014513d5dd8ffe9a8a13bf7bcd5f381217fc4a2604bd04fa68c`；桌面与移动参考 `prototype-usage-{1280,390}.png`。用户提供的两张 Safari 截图分别为测试站和原型的同屏对照。

## 正式结构

`/usage` 页面标题后有三个连续工作面：概览（顶部时间范围和粒度控制，下面四项等宽统计及细分隔线）、分析（桌面 2×2 的模型/线路/端点/趋势，窄屏逐项堆叠，内部细分隔线）、记录（筛选、操作、明细形成一个工作面）。图表与统计继续使用真实 API、当前用户的金额/空态/失败/重试语义；演示余额、使用数据和原型线路名称不进入实现。已确认的 `$` 两位小数及统计缺失时的横线保持不变。

## 实现边界

只调整用户端 `UsageView.vue` 的布局、该页面的内部样式和对应结构测试；共享后台统计/图表组件不改变默认外观。若需在页面内取消它们原来的卡片边框，通过该页专用类限制作用域。日期、粒度、图表指标、筛选、导出、明细和失败重试维持原有绑定。保留原型没有涵盖但真实站已有的筛选/错误请求入口，不删除功能。

## 验证与交付

先写会失败的结构测试，再完成最小布局；运行相关测试、类型检查、构建，并在 1280×900、390×844 对比冻结原型和候选页面。其他五个原型页以同两尺寸和步骤做对照，按一致、实现偏差、数据/接口未验分类；未经用户再次授权不推送或部署测试站，也不宣布整版验收通过。
