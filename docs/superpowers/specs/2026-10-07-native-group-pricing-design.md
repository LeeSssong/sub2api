# 扣费标准动态原生数据设计

用户要求价格弹窗的分组、支持模型、倍率和扣费公式随 Sub2API 原生数据更新，支持模型与该用户同分组普通 `/v1/models` 清单一致。

- 分组来源 `/api/v1/groups/available`，只显示当前工具对应的活跃可访问分组。原生响应附带从已有工具映射仓储读取的 tool_ids，显式映射优先，空数组回到平台默认。首页传入分组仅作为旧后端兼容提示，名称、可见性、默认倍率从新响应读取。
- 模型来源 `/api/v1/groups/available-models`。后端复用普通模型列表的候选来源、回退及白名单规则，并补齐用户禁用模型和固定账号目录。固定目录失败时返回错误，不能用另一份模型清单冒充成功。
- 倍率来源 `/api/v1/groups/rates`；有用户专属倍率时优先使用，否则使用最新分组 `rate_multiplier`。保留零倍率，扣费公式与倍率字段取同一数值。
- 每次打开及手动刷新先并行读取分组和倍率，再携带当前工具分组 ID 查询模型；后端将 group_ids 与授权分组相交，避免无关固定目录失败影响当前工具。三份数据成功后统一更新，打开期间每 60 秒更新；隐藏页面暂停，重新可见立即更新，关闭或卸载取消请求和定时器。刷新失败隐藏失效数据并允许重试；切换工具不接受旧请求结果。
- 现有官方价格档位、布局及品牌保留。刷新入口使用图标与可见文字。空模型目录显示“暂无可用模型”，不制造模型名称。

本次只做本地实现及直接相关验证，不提交、推送或部署，不修改真实分组配置、数据库或账务逻辑。模型一致性验证针对默认普通 `/v1/models` 路径；强制平台路径和 Codex 专用清单有各自协议语义。
