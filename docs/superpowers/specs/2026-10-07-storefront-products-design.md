# 云猫嵌入默认定位商品区

用户确认进入兑换页后，云猫区域优先展示商品，保留完整店铺及新窗口入口；本次仅本地实现、验证，不提交、推送或部署。

## 已核实与方案

- 现有 RechargeStorefront 使用跨域 iframe。公开店铺当前商品区标题约在内部 y=420px，没有可用商品区 DOM id 或已确认的跨域定位协议。
- 仅对 https://catfk.com/shop/DLK8SNUJ 的当前入口应用 400px 初始显示偏移。其他配置的店铺照常从顶部展示。
- 用可滚动外层窗口移动初始显示位置，不读取或操作跨域文档。商品模式内 iframe 高度等于窗口高度加两倍偏移，使居中订单弹窗仍落在可见窗口中；不采用负 margin 或永久裁切。
- 窗口商品模式至少 760px 高、iframe 至少 720px 宽。窄屏可横向滑动查看三个商品及完整弹窗；提示滑动并保留原有新窗口购买入口。
- “查看完整店铺”与“定位购买区”切换不更换 iframe，保留购买中的状态。完整模式恢复既有至少 1100px 的高度，并从窗口顶部显示。
- iframe 后续整页加载时恢复完整模式，防止对支付/订单页面套用店铺偏移；URL 变化重新初始化。首次异步加载不覆盖用户已选择的完整模式。

## 验证与边界

单测覆盖入口限制、模式切换、首次与后续加载、URL 变化；浏览器使用真实云猫页面验证桌面/窄屏商品定位和订单确认弹窗，不提交订单、不付款。兑换页原有测试继续通过。云猫将来修改页面结构会影响固定偏移，完整店铺和新窗口为恢复入口；不声称已验证真实付款。
