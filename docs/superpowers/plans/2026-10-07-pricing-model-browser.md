# 原生价格表排序、筛选与稳定刷新

目标：按用户截图要求改进现有弹窗，仍使用原生价格与分组接口。

设计：OpenAI 使用官方价格页分类：旗舰、网络安全、图像生成、实时和音频生成、转录、专用；补充其他保留未知模型。类型筛选只作用上方价格表，不隐藏分组授权模型。排序使用核实的官方发布元数据及官方快照ID白名单；未知时间排在已知时间之后，同日期稳定排序。元数据只描述分类和排序，不存价格，原生名单不扩增。其他提供商保持原列表。

每个原生模型只占一个tbody行，模型名显示一次。移除独立上下文列，在模型名下给出原生阈值说明，各价格单元格按短/长上下文分段；三档及以上按第N档，不丢价格或5分钟/1小时缓存写入。

刷新根因：60秒轮询和visibility恢复都会使loading为true；v-if loading因此卸载表格。初次请求保留加载提示，后续请求只更新刷新按钮，表格与筛选持续存在；后台失败停止显示过时价格并提供重试；回到页面仅当成功读取超过60秒或存在错误才静默同步，避免每次切换窗口重取。请求竞态、关闭取消保持。
