# 线路检查每分钟限流

目标：每个登录用户在任意连续 60 秒内最多发起 30 次线路检查，一次批量检查计一次，额度跨标签页、脚本和实例共享。第 31 次返回 429、专属错误码、Retry-After 和等待秒数。Redis 不可用时返回 503，避免探测绕过限制。面板限流配置关闭或管理员豁免均不关闭此限制。

方案：复用原生 Redis 限流器，新增滑动窗口原语和检查线路专属中间件，只挂载 POST /monitor-v4/check。保留现有全局与 Heavy 限流。页面显示明确中文提示，超限时短暂禁用检查按钮，到期可重试；后台刷新不消耗专属额度。
