# 价格弹窗复用原生模型广场价格

**目标：** 按用户已确认的方案，移除弹窗静态价表，直接复用模型广场与计费同源的官方参考价格解析。

**架构：** 既有授权 `/groups/available-models` 在 `include_pricing=true` 时附带与模型广场相同的价格 DTO；模型仍来自普通原生模型列表，先过滤授权与禁用模型再查询价格。`ModelPlazaService` 提供批量查询方法，复用现有 lookupOfficialPricing；应用装配复用已有服务实例。公开广场开关不影响用户弹窗，不新增价格目录、依赖、迁移或账务规则。

**界面：** 保留价格弹窗与下方分组倍率表。上方展示 Standard 原生参考价（美元/100万 Token）和原生上下文阶梯，缺失项显示“—”并说明目录未提供。不维护或推算原生广场未提供的其他服务档位。单档标注全部上下文；多档使用原生阶梯标签，不丢失第三档。缓存写入保留原生5分钟/1小时区分。

**步骤：**

- [x] 新增组件失败测试：接口价格覆盖旧常量、日期别名、阶梯、多档、零价格、字段缺失、动态刷新。
- [x] 新增服务/端点测试：批量解析与模型广场同源，授权后查询、禁用与未授权模型不返回价格，默认模型列表保持兼容；缺少价格服务返回503，非法参数返回400。
- [x] 导出批量解析方法，装配已有模型广场服务；端点复用现有 DTO。
- [x] 前端请求携带 include_pricing；替换静态表和不受支持档位，保留取消/竞态/60秒同步行为。
- [x] 运行 PricingDialog、首页、价格适配测试，typecheck/build/相关lint、Go定向测试与编译；桌面手机本地真实组件 mock 验收。
- [ ] 测试站发布门禁补充本次精确文件并验证；按已有授权从干净且已推送main蓝绿更新测试站，核对版本、资源和健康；真实登录验收仍受既有凭据失效限制时如实记录。

**验收边界：** 这是原生系统的官方基础参考价，不覆盖分组/渠道自定义单价；实际扣费仍由原生计费、服务档位、上下文与有效倍率决定。未知价格不补静态值，非 token 模型不会冒充有 token 参考价。
