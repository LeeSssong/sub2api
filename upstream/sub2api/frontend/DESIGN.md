# 星桥 UI 设计规则

## 刷新操作

- 全局手动刷新按钮统一采用「刷新图标 + 刷新文字」，以密钥页工具栏为视觉基准。适用于用户端、管理端、弹窗、详情面板和错误恢复入口。
- 使用项目 Icon 的 `refresh` 图标，放在文字左侧；文字使用 `t('common.refresh')`，中文显示「刷新」。不得只显示图标、只显示文字，或仅通过 tooltip、aria-label、sr-only 提供文字。
- 使用现有 `btn btn-secondary` 次要按钮体系，图标与文字水平排列并保持间距；深色用户端沿用深色底、细描边和圆角。窄屏仍保留图标和文字，允许工具栏换行，不裁切成固定宽度的图标按钮。
- 保留刷新范围、事件、加载和禁用逻辑；加载动画作用于图标，文字持续可见。提供键盘焦点反馈。
- 自动刷新开关、重试、同步、重新授权和刷新凭据属于不同操作，保留准确的动作名称，不因复用刷新图标而改称普通「刷新」。
- 新增或修改刷新入口时检查默认、加载、禁用及窄屏状态，避免再次出现两套表达。
