# 星桥 AI Link · 完整浏览器交互版

依据现有 Figma 文件 `0ubs8eGtuQk760tHbHtXca` 的六个业务页面及当前原型结构文档、DESIGN.md 实现。不是首次使用向导，不修改正式 Figma。

## 启动

在项目根目录执行：

```sh
node prototype/server.mjs
```

打开 `http://127.0.0.1:4173`。仅监听本机，不公开部署。无需安装 npm 依赖。更换端口：`PORT=4174 node prototype/server.mjs`。

## 演示数据

右下角“交互演示 · 示例数据”可以恢复初始数据、切换首次使用场景，或模拟密钥创建、订单创建、线路统计、使用统计、使用明细、地区查询和 CSV 导出失败。

- 兑换 `DEMO30`：增加 $30.00 演示额度，每次重置后限一次。
- 兑换 `PLUS2`：增加 2 路演示并发，每次重置后限一次。
- 邮箱与两步验证的验证码：`123456`。
- 身份验证信息：`DEMO`。
- 创建订单后进入页面内 sub 原生支付承接工作面；原型不会打开真实渠道，也不向普通用户提供指定支付成功或失败的模拟按钮。
- 待支付订单可以从承接工作面或订单列表二次确认取消；取消后清除本地恢复快照。
- 密钥带 `DEMO-ONLY` 标识，端点为 `.example`，不能用于真实接入。
- 使用、地区、价格、统计和排序数据均为示例，不代表真实运营数据或承诺。
- 请求错误按对应工作面展示并提供原位恢复入口；筛选或刷新只在模拟读取恢复后清除错误。地区查询会先显示“查询中…”，私网地址直接显示“内网地址”。

变化仅保存在当前浏览器的 `starbridge-interactive-v1` localStorage 中。模型与前端没有后端请求，不会发送验证码或写入真实 CCS；客服入口不提交工单，沿用 QQ 群与公共联系方式。密码只验证匹配并更新布尔演示状态，不存储密码内容。刷新页面会清空本次线路检查结果，其余演示操作保留。

## 响应式基准

- `1280×900`：完整侧栏，六页按窄桌面布局展示。
- `900×1000`：200px 侧栏，工具与统计两列、图表单列、充值上下排列。
- `390×844`：76px 图标侧栏，内容重排；密钥、使用记录和订单表格在各自滚动容器内横向浏览，不产生页面级横向溢出。
- `1395×675`：创建线路密钥高级限制项全部展开时，弹窗保持在视口内并可滚动到“取消 / 创建”操作。

## 与静态 Figma 的必要区别

- Figma 各画板的示例计数彼此不一致，浏览器版本使用统一数据源，因此列表条数、Token、费用等会随操作变化，不硬编码为截图数字。
- 暂未确认的配置计数采用演示口径：仍存在的密钥（含禁用密钥）按线路去重；历史停用线路保留，工具按钮只依据管理正常线路覆盖情况判断。此规则未回写正式文档。
- 手动检查更新示例线路统计和可用性，不扣账户余额、不创建个人消费明细。
- 图表各项与概览、CSV 及请求明细使用同一份已应用筛选；超过三种分类时汇总“其他”。
- 金额展示沿用原画板的美元额度和人民币支付示例，不引入真实汇率或定价。
- 桌面布局依据现有 Figma；窄屏仅做容纳和横向滚动，不视为新的移动端设计决策。
- 未加入“开始连接”或分步新手引导；之前暂缓事项仍暂缓。

## 文件

- `model.mjs`：数据、校验和业务联动。
- `ui.mjs`：通用 DOM 文本、弹窗、复制和导出。
- `pages.mjs`：六页布局和统计图表。
- `dialogs.mjs`：线路、密钥、账号、订单等弹层。
- `app.mjs`：事件、路由、持久化和状态。
- `styles.css`：品牌令牌及页面样式。
- `assets/`：从 Figma 下载的原始图标；不使用临时远程图标链接。
- `tests/model.test.mjs`：模型行为测试。
- `qa/`：桌面截图与验收记录。

# 用户端 Prototype

本原型的 `native/dist` 来自测试站当前代码 `2e43f835e9fb1fbdf753c1dcd66e0335f815fff9`，用于逐页复现测试站用户端。

启动：

```bash
node prototype/native/server.mjs
```

访问 `http://127.0.0.1:4174/`。原型使用隔离的浏览器存储和虚构用户数据；所有支付、邮箱验证码、Passkey、CCS 导入和真实线路检查均不会连接测试站，也不会产生外部副作用。

`prototype/` 下的旧版原型源码仍保留用于历史交互测试；当前视觉对照入口是 `prototype/native/dist`。
